## Bugs and feature requests

Use the GitHub issue templates. Include the version or commit, the installation method, and
a minimal reproduction.

## Security

Do not open a public issue for a vulnerability. Follow [SECURITY.md](SECURITY.md).

## Support scope

The open-source project is maintained on a best-effort basis. There is no guarantee of
response time, commercial support, or long-term support for old versions.

For professional support, hosting, or custom development, contact **it.specialist.gasca@gmail.com**.
